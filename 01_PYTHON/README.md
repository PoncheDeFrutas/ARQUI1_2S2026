# Python y GPIO con Raspberry Pi

Ejemplos progresivos para practicar Python con los pines GPIO de una Raspberry Pi.

## Preparación

Sigue la guía [Preparar un entorno Python](./documentación/preparar%20entorno%20Python.md) y consulta [GPIO y sensores](./documentación/gpio%20y%20sensores.md) antes de conectar el hardware.

## Lecciones

- [00 — Blink](./lecciones/00_blink/README.md): salida digital con un LED.
- [01 — Botón como entrada](./lecciones/01_input_button/README.md): sondeo, interrupciones y debounce.
- [02 — PWM](./lecciones/02_pwm/README.md): tonos en buzzer y barrido de servo.

Ejecuta cualquier ejemplo desde la raíz con `uv run ruta/al/ejemplo.py`.
